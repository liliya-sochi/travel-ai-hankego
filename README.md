# HankeGo

> 🚧 Working title

HankeGo is an AI-powered travel platform designed to help people plan, organize and enjoy their journeys.

The project is being developed as a real production-style application while learning modern backend development, AI engineering and cybersecurity.

---

## Goals

- Build a production-ready backend
- Learn AI Engineering through practice
- Learn Cybersecurity alongside development
- Build a scalable travel platform
- Create a portfolio project for technical interviews
